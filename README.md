项目希望用清爽的卡片界面和舒服的乱序词表，让背单词这件事更轻松。词库覆盖初中、高中、大学英语四六级、考研、托福和 SAT，适合不同阶段的学习者。

## 功能特点

- **多级词库**：支持初中、高中、CET4、CET6、考研、托福和 SAT 词库，词库用胶囊按钮一键切换，并显示当前序号与词库总量。
- **完整单词信息**：展示美式/英式音标、中文释义、例句和常用短语，点击音标按钮即可播放对应发音。
- **全词库搜索**：输入英文单词后优先搜索当前词库，未找到时自动搜索其他词库并跳转到结果。
- **灵活切词**：可点击“上一个 / 下一个”，也可使用键盘 `←` / `A` 和 `→` / `D` 快速切换；**移动端支持在单词卡片上左右滑动翻页**。
- **按序号跳转**：输入词库中的单词序号，即可直接定位到对应单词。
- **释义显隐**：一键隐藏或显示释义、例句和短语，适合先回忆、再核对答案。
- **生词管理**：点击“不会”收藏生词；重复标记时会给出提示，也可以随时移除已掌握的单词。
- **生词直达**：在“不会的单词”列表中点击单词，可在新页面直接打开对应详情。
- **导出 Word**：将不会的单词及其释义导出为 `.docx` 文件，方便打印或离线复习。
- **学习进度记忆**：自动保存当前词库及各词库的学习位置，下次打开可以继续学习。
- **个性化背景**：默认使用在线随机壁纸（来自 [wallpaper-daily](https://wallpaper-daily-three.vercel.app)，站点通过 Pages Function 做同源代理，接口不可用时自动回退），也可切换内置的多套动态渐变；背景与释义显示偏好会被自动记住。
- **反馈入口**：可在「设置&反馈」中提交使用建议或问题。数据写入自己的 Supabase（表 `user_feedback`），并且**只写不读**——前端拿不到别人提交的内容，只有站点所有者能在后台看到。想关掉的话把 `VITE_FEEDBACK_ENABLED` 设为 `false`（见 `.env.example`）。
- **响应式布局**：适配桌面端与移动端——移动端提供固定在底部的操作栏（上一个 / 不会的单词 / 设置 / 下一个），并适配刘海屏安全区。

> 学习进度、生词、背景和释义显示偏好保存在当前浏览器的本地存储中。清除浏览器站点数据后，这些记录也会被清除。

## 如何使用

1. 打开 [Word Wind 在线版](https://word-wind-study.pages.dev)，从左侧词库选择适合自己的学习范围。
2. 使用页面按钮或键盘快捷键浏览单词；手机端可以直接在单词卡片上左右滑动翻页；需要定位时，也可以直接搜索单词或输入序号跳转。
3. 想先测试记忆效果时，点击“隐藏释义”；回忆完成后再点击“显示释义”核对。
4. 遇到不熟悉的单词，点击卡片底部的“不会”加入生词列表。
5. 打开“不会的单词”进行复习、删除已掌握的单词，或导出 Word 文档。
